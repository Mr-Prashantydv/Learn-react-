# Reactoria curriculum

The player knows basic JavaScript (variables, functions, arrays, objects,
arrow functions) and nothing about React. Thirteen regions take them to
mastery. Each region may only *require* what earlier regions taught.

| # | Region (chapter id) | Key (prefix) | Teaches |
|---|---|---|---|
| 1 | Shore of JSX (`jsx-shore`) | `jsx` | What React is, declarative UI, components as functions, JSX, `{}` expressions, the 3 JSX rules, fragments, `className`, style objects, `export default`, `createRoot` (conceptually) |
| 2 | Component Forge (`component-forge`) | `forge` | Defining & nesting components, composition, **props** (strings, numbers, booleans, objects, functions as data), destructuring props, default values, `children`, passing JSX as props, props are read-only, **pure components** (same input → same output, no side effects in render), named vs default exports (conceptual), `{...props}` spreading (brief) |
| 3 | Branching Woods (`branching-woods`) | `woods` | Conditional rendering (`if`/early return, ternary, `&&`, `null`), the `0 &&` gotcha, lists with `.map()`, **keys** (why, good keys, why not index for dynamic lists), `filter` + `map`, sorting copies (`toSorted`/spread), extracting list items into components, nested lists |
| 4 | State Springs (`state-springs`) | `springs` | Events (`onClick`, passing vs calling handlers, the event object, handler props like `onSelect`), `useState`, why local variables don't work, state is per-instance, **render → commit**, **state as a snapshot**, batching, **updater functions** `setX(x => x + 1)`, multiple state variables, `preventDefault`/`stopPropagation` |
| 5 | Immutable Isles (`immutable-isles`) | `isles` | Treating state as read-only, updating **objects** (spread, nested spread), updating **arrays** (add/remove/update/insert/replace via spread, `filter`, `map`, `toSorted`), why mutation doesn't re-render (`Object.is`), **choosing state structure** (avoid redundant/duplicated state, store ids not copies, derive values during render) |
| 6 | Form Fortress (`form-fortress`) | `fort` | **Controlled inputs** (text, textarea, select, checkbox, radio), form `onSubmit` + `preventDefault`, one handler for many inputs (`name` + computed keys), validation & derived values, disabling submit, **lifting state up**, single source of truth, controlled vs uncontrolled (`defaultValue`, `FormData` briefly) |
| 7 | Effect Volcano (`effect-volcano`) | `volcano` | Side effects & purity, `useEffect`, dependency arrays (none / `[]` / `[x]`), **cleanup** (intervals, listeners), StrictMode double-run in dev (why), **fetching data** (loading / error / data states), race conditions with an `ignore` flag, **you might not need an effect** (derive during render, do it in the event handler) |
| 8 | Ref Ruins (`ref-ruins`) | `ruins` | `useRef` for values that don't trigger renders (timer ids, previous values, counters), refs vs state, **DOM refs** (focus, scroll, measure/select), **`ref` as a prop** on function components (React 19) and `forwardRef` (legacy, recognise it), `useImperativeHandle` (brief), when NOT to use refs |
| 9 | Context Canopy (`context-canopy`) | `canopy` | **`useReducer`** (actions, pure reducers, `switch`, dispatch), when reducer vs state, **prop drilling**, `createContext`, providing (`<Ctx value={...}>` in React 19, `<Ctx.Provider>` older), `useContext`, default values, context + state (theme), **context + reducer** pattern (state & dispatch providers), when not to use context |
| 10 | Hook Workshop (`hook-workshop`) | `hook` | **Rules of Hooks** (top level only, only from components/hooks — and why: call order), **custom hooks** (`use` naming, sharing logic not state), `useToggle`, `useLocalStorage`, `useFetch`, `useInterval`/`useDebounce`, composing hooks, returning arrays vs objects |
| 11 | Performance Peaks (`performance-peaks`) | `peaks` | When components re-render (state change, parent render, context), state preserved by **position** in the tree, **resetting state with `key`**, `React.memo`, `useMemo`, `useCallback`, state colocation, **`useTransition`** and **`useDeferredValue`**, the React Compiler (concept), measuring before optimising |
| 12 | Arcane Spire (`arcane-spire`) | `spire` | **Error boundaries** (class component basics), **portals** (`createPortal`), **`Suspense`** + **`lazy`**, **`use(promise)`**, **Actions** (`<form action>`), **`useActionState`**, **`useFormStatus`**, **`useOptimistic`**, `useId`, **Server Components** & `'use client'`/`'use server'` (concepts), the ecosystem: frameworks (Next.js, React Router), TypeScript, testing |
| 13 | The Mutator's Citadel (`mutator-citadel`) | `citadel` | Capstone: multi-stage final quests combining everything (reducer + context, effects + fetch, custom hooks, memoisation, forms), a final review trial, and the final boss **The Mutator** (`final: true` on the last level) |
